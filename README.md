# BEING Biro Psikologi 2.0

Versi uji frontend yang siap dipasang di GitHub Pages.

## Cara unggah
1. Buat repository baru, misalnya `being-biro-psikologi`.
2. Unggah seluruh isi folder ini ke root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/root`.
5. Simpan dan tunggu URL GitHub Pages aktif.

## Mode demo
Klik **Masuk**, lalu pilih:
- Klien
- Profesional
- Admin

Kontak WhatsApp admin disimpan di tombol bantuan dan tidak ditampilkan sebagai nomor di antarmuka.

## Status
Frontend/PWA siap uji. Login, database, chat nyata, pembayaran, dan laporan PDF akan dihubungkan melalui Supabase pada tahap berikutnya.
